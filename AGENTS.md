# Agent instructions

## Development observability

For software behavior, architecture, test, or UI work in this repository, use the `visual-dev-console` skill at `.agents/skills/visual-dev-console/SKILL.md`.

Apply red/green TDD to behavior changes and keep the project-local `report.html` connected to real test runs. The report should help a person understand the architecture and workflows through actual inputs, outputs, test results, and screenshots for visual behavior, as described in the skill.
